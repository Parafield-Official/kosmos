Get Kosmos.Keep the book.

Free desktop app for Mac and Windows. Double-click. No terminal, no account, no “clone the repo” unless you want the source.

macOS

Download for Mac

Apple silicon. Open the disk image and drag Kosmos to Applications. If Gatekeeper blocks an unsigned pre-release, right-click the app and choose Open.

Windows

Download for Windows

64-bit installer. If SmartScreen appears for an unsigned pre-release, choose More info → Run anyway.

Download 64-bit · Windows 10 or later

Already have the first public build? Download this one once and replace the old app. After that, Kosmos checks GitHub and installs later versions itself. Your book folder stays where it is.

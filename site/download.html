Download

Get Kosmos.Keep the book.

Free desktop app for Mac and Windows. Double-click. No terminal, no account, no “clone the repo” unless you want the source.

Mac

Apple silicon. Open the disk image and drag Kosmos to Applications. The release is Developer ID signed and notarized by Apple.

Download .dmg

Windows

64-bit installer. If SmartScreen appears for an unsigned pre-release, choose More info → Run anyway.

Download .exe

Already have the first public build? Download this one once and replace the old app. After that, Kosmos checks this GitHub Pages update channel and installs later versions itself. Your book folder stays where it is.

Source on GitHub

Kosmos is MIT-licensed. Read the code, open an issue, or build it yourself. The same repository hosts these installers.

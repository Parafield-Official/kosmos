FAQ

Straight answersfor the booth.

If a question is about replacing a DAW, cloning a voice, or catching acting — the answer is no. If it is about keeping the book on this machine, the answer is yes.

Is Kosmos free?

Yes. $0. MIT license. No account, no trial clock, no per-finished-hour meter. Download the Mac or Windows build, or clone the source.

Does my book leave this computer?

Prep, proof, the following page, ACX check, master, and export all run locally. There is no sign-in and no cloud copy of the manuscript. Live together is an invite between two desks you choose — including hotel Wi-Fi and a phone hotspot — not a store and not an upload.

Is this an AI narrator?

No. Kosmos never reads the book and never clones a voice. It is a desk for a human take against a human manuscript.

Does it replace Reaper or Audition?

No. Working narrators still record and punch in the editor they trust. Kosmos is the script, the proof, the pickup list, and the ACX pack beside that editor. DIY authors get an optional simple recorder — record, stop, punch one line — not a multitrack desk.

What will it catch?

Words that do not match the page, long mid-sentence pauses, and ACX numbers (loudness, true peak, noise floor, format). It will not catch acting, character voices, mouth clicks, or echo. A human still listens.

How do an author and a narrator share a book?

Save a name and a role. Create an invite — a code plus three spoken words. The other desk joins with the reply. You work the same project: notes, pickups, names, takes. No zip pack required for the live path. If a network blocks the live link, you can still hand the project folder across.

How much does this save?

A 10-hour title on the usual paid slices — a following page, a proof pass, and an ACX master — is typically $330 or more before a DAW license (PromptVO Indie + Pozotron pay-as-you-go + chapterpass, August 2026 list prices). Kosmos covers those jobs for $0. You still own a DAW if you already have one.

Mac or Windows?

Both. A disk image for Apple silicon Macs and an installer for 64-bit Windows. Drag to Applications, or run the installer. This is a pre-release: if Gatekeeper or SmartScreen stops an unsigned build, open it from the context menu / More info.

How do I get a new version?

Installed copies check GitHub for a later release and download it in the background. Restart when you are not recording. If you still have the first public installer, download the current Mac or Windows file once and replace that app — later versions then arrive in Kosmos. Your book folder is unchanged.

Where is the source?

On GitHub, same place as the downloads: github.com/Parafield-Official/kosmos. Issues and pull requests belong there.
